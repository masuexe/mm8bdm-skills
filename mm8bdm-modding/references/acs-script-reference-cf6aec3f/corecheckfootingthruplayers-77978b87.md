# core_CheckFooting_ThruPlayers

> ⚡ script "core\_CheckFooting\_ThruPlayer" (void)

## Usage

---

Checks if the activator is standing on floor or on a solid actor, that is not a player.

### Return Value

- Returns true if the actor is standing on a solid actor that isn’t a player, false if it is not.
