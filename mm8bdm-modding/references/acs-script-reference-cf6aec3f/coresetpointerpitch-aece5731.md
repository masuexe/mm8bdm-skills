# core_setpointerpitch

> ⚡ script "core\_setpointerpitch" (int pitch, int ptr)

## Usage

---

Sets the pointer’s pitch to the given value.

### Parameters

- `pitch`: int - The pitch to change to, in degrees.

- `ptr`: int - The [actor pointer ](https://zdoom.org/wiki/Actor_pointer)of the actor being modified.
