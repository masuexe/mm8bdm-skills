# core_bringplayerhere

> ⚡ script "core\_bringplayerhere" (int num, int freeze)

## Usage

---

> 💡 **This script is not intended to be called in code, instead it is a debug script which should be called via using the **[`pukename`](https://zdoom.org/wiki/CCMDs:Debug#pukename:~:text=cannot%20be%20puked.-,pukename,-%3Cscript%3E%20%5Balways%5D%20%5Barg1)** command in console!**

This script can be used to bring another player to in front of you when called.

### Parameters

- `num`: int - The player number of the player to bring to you

- `freeze`: bool - If true, it will freeze the player alongside bringing them to you
