# core_setTIDsPointerToThis

> ⚡ script "core\_setTIDsPointerToThis" (int tid, int pointer)

## Usage

---

This script is used to set a selected actor pointer of `tid` actor to the calling actor.

### Parameters

- `tid`: int - The TID of the actor to manipulate

- `pointer`: int - Which actor pointer field to assign the calling actor to
