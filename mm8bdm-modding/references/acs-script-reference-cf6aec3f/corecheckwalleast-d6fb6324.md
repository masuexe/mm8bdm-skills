# core_checkWall_east

> ⚡ 
>
> script "core\_checkWall\_east" (void)

## Usage

---

Checks if there is a solid object / wall a small distance to the east of the calling player.

### Return Value

- Returns true if there is some solid object / wall, false otherwise.

> 🚨 **This script currently returns false for 3D floors!**
