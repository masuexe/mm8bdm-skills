# core_targetyawpitch

> ⚡ Script "core\_targetyawpitch" (int PitchAngle)

## Usage

---

This script can be used to set the calling actor’s pitch and / or angle to match that of its `AAPTR_TARGET` actor pointer.

### Parameters

- `PitchAngle`: int - Determines the mode of the script. Below are following modes:
  - 0: Set only the pitch to match.

  - 1: Set both the pitch and angle to match.

  - 2: Set only the angle to match.
