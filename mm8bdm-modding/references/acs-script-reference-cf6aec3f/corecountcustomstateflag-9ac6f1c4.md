# core_count_customstateflag

> ⚡ script "core\_count\_customstateflag" (void)

## Usage

---

This script can be used to return the currently stored custom state for the calling actor, after having used either [core_updatecustomstate](./coreupdatecustomstate-9529446f.md) or [core_set_customstateflag](./coresetcustomstateflag-f7cd58de.md).

### Return Value

Returns the currently stored custom state as an integer.
