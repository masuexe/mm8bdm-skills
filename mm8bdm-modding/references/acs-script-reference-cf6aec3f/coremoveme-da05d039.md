# core_moveme

> ⚡ script "core\_moveme" (int velx, int vely, int velz)

## Usage

---

> 💡 **This script is not intended to be called in code, instead it is a debug script which should be called via using the **[`pukename`](https://zdoom.org/wiki/CCMDs:Debug#pukename:~:text=cannot%20be%20puked.-,pukename,-%3Cscript%3E%20%5Balways%5D%20%5Barg1)** command in console!**

Causes the calling player to move in one direction infinitely until they press their use button (`+USE`).

### Parameters

- `velx`: int - The X velocity to move at

- `vely`: int - The Y velocity to move at

- `velz`: int - The Z velocity to move at
