# core_getmaster

> ⚡ script "core\_getmaster" (int l)

## Usage

---

A script that can be called to get the TID of the calling actor’s `AAPTR_MASTER` actor pointer.

### Parameters

- `l`: bool - If true, logs the returned TID to chat. Useful for debugging!

### Return Value

Returns the TID of the calling actor’s `AAPTR_MASTER` actor pointer.
