# core_getspeed

> ⚡ script "core\_getspeed" (int l)

## Usage

---

Gets the current moving speed of the calling actor.

### Parameters

- `l`: bool - If true, logs the speed to chat. Useful for debugging!

### Return Value

Returns the current moving speed of the calling actor as a [fixed point number](https://zdoom.org/wiki/Fixed_point_number).
