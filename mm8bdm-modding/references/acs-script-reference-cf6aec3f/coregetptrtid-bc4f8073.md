# core_getptrtid

> ⚡ script "core\_getptrtid" (int ptr)

## Usage

---

A script that can be called to get the TID of a selected [actor pointer](https://zdoom.org/wiki/Actor_pointer) for the calling actor.

### Parameters

- `ptr`: int - Which actor pointer to retrieve the TID of.

### Return Value

Returns the TID of the selected actor pointer for the calling actor.
