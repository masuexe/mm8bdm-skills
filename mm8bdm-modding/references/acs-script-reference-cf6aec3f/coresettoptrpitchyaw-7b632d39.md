# core_SetToPtrPitchYaw

> ⚡ script "core\_SetToPtrPitchYaw" (int ptr)

## Usage

---

Copies the pitch and angle of the given pointer and applies those to the calling actor.

### Parameters

- `ptr`: int - The [actor pointer ](https://zdoom.org/wiki/Actor_pointer)of the actor being looked at.
