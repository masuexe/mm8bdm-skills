# core_checkWall_west

> ⚡ script "core\_checkWall\_west" (void)

## Usage

---

Checks if there is a solid object / wall a small distance to the west of the calling player.

### Return Value

- Returns true if there is some solid object / wall, false otherwise.

> 🚨 **This script currently returns false for 3D floors!**
