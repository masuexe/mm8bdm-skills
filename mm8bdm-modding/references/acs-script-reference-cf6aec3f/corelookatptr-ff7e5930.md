# core_lookatptr

> ⚡ script "core\_lookatptr" (int ptr)

## Usage

---

This script rotates the activator’s angle and pitch to look towards the given pointer.

### Parameters

- `ptr`: int - The [actor pointer](https://zdoom.org/wiki/Actor_pointer) of the calling actor to look at.
