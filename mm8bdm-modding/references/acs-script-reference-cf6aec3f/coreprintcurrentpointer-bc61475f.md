# core_printcurrentpointer

> ⚡ script "core\_printcurrentpointer" (int pointer)

## Usage

---

This script will print the actor name of the given actor pointer of the calling actor. This is useful for debugging to make sure an actor is getting the right pointers.

### Parameters

- `pointer`: int - The [actor pointer](https://zdoom.org/wiki/Actor_pointer#:~:text=Actor%20pointers%20are%20used%20to,or%20which%20ones%20they%20spawned.) of the calling actor to print out.
