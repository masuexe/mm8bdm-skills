# core_getmaxhealth

> ⚡ script "core\_getmaxhealth" (int ptr)

## Usage

---

Returns the max health of the calling actor (or a selected actor pointer of the calling actor).

### Parameters

- `ptr`: int - An optional [actor pointer](https://zdoom.org/wiki/Actor_pointer) to use in lieu of the calling actor.

### Return Value

Returns the max health of the actor selected.
