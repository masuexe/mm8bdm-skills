# Gel Table

> 🚨 **Warning!** This feature is reliant on a **change of mapping standards. **Custom maps made prior to <u>**version 6a**</u>** **may not support this table.

> 📦 8BDT.acs

## Usage

---

Stores information about all gel sectors on the map. See more information about how to interact with this table in the page for [gel sectors](../mapping-reference-3fe89cb4/gel-sector-33d9857a.md).

### Constants

- `GLOBAL_GEL_TID`: -9998 - The default “tag” to apply gel to every sector in the map

### Static Variables

- `MAX_GEL_GLOBAL`: int - Count of stored gel sectors in the map.

### Fields

- `tag`: int - The tag of the gel sector (-9998 if applying to all sectors)

### Utility Functions

> ⚡ int findGelByTag(int tag)

- Parameters:
  - `tag`: int - The sector tag to search for

- Return values:
  - Index of the gel actor (starting from 0), if one is found

  - -1 if none is found

> ⚡ bool isZPosInGelTag(int tag, int zPos)

- Parameters:
  - `tag`: int - The sector tag affected by gel

  - `zPos`: fixed - Vertical position being checked

- Return values:
  - True if `zPos` is in gel, false otherwise

> 💡 **Entering a tag that does not have gel could return unpredictable results. Make sure to validate the sector tag you have is a valid gel tag.**

> ⚡ int findActorGel(int tid)

- Parameters:
  - `tid`: int - Thing to search the gel table for

- Return values:
  - Sector tag affected by gel, if the given TID is found within one

  - 0 if none is found

### Getters

Each of the following returns the value of their given property, given a table index.

> ⚡ int getGelTag(int idx)

### Setters

Each of the following changes the value of their given property, given a table index.

> ⚡ void setGelTag(int idx, int val)
